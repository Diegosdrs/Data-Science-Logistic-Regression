# Harry Potter and the Data Scientist 🧙‍♂️✨

Ce projet est un cas pratique inspiré de l’univers de **Harry Potter**, dont l’objectif est de **prédire la maison de chaque étudiant à Poudlard** à partir de ses notes et caractéristiques.

---

## Étapes du projet 🚀

### 1️⃣ Analyse de données (Data Analysis)
* Compréhension du dataset : identification des types de données, détection des valeurs manquantes ou aberrantes. 🧐
* Calcul manuel de statistiques descriptives (moyenne, écart-type, min/max, quartiles) **sans utiliser de fonctions toutes faites** 📊.

### 2️⃣ Visualisation des données (Data Visualization)
* Exploration des relations entre les variables via **histogrammes, scatter plots et pair plots** 📈.
* Identification des matières avec des distributions homogènes et des features pertinentes pour la modélisation 🔍.

### 3️⃣ Régression logistique multiclasses (Logistic Regression)
* Implémentation d’un classificateur **one-vs-all** pour prédire la maison des étudiants 🏠.
* Utilisation de la **descente de gradient** pour entraîner les modèles et générer les poids (θ) ⚡.
* Prédiction des maisons sur un dataset test et génération d’un fichier de résultats `houses.csv` 📄.

---

## Connaissances et compétences acquises 🧠

* **Analyse statistique** : calcul manuel de statistiques de base pour explorer les données 📊.
* **Nettoyage et préparation des données** : gestion des valeurs manquantes, normalisation et standardisation 🧹.
* **Visualisation** : création de graphiques pour mieux comprendre les données et identifier les patterns 🎨.
* **Machine Learning supervisé** :
    * Compréhension de la régression logistique et de son fonctionnement pour la classification 🤖.
    * Implémentation du one-vs-all pour les problèmes à plusieurs classes 🔢.
    * Utilisation de la descente de gradient pour optimiser les poids ⚡.
* **Programmation Python avancée** : manipulation de `numpy` et `pandas`, écriture de scripts modulaires et reproductibles 🐍.
